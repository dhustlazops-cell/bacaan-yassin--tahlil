# Bacaan Yasin & Tahlil

A responsive public reading website for the family Majlis Yasin, Tahlil and Doa Arwah.

## Features
- Three memorial cover themes: black/gold, black/silver, and ivory/rose.
- Quran text, Malay translation and transliteration loaded from AlQuran Cloud.
- Continuous full-surah recitation audio for complete surahs.
- Sequential playback for selected Al-Baqarah passages.
- Responsive reading layout and numbered contents.

## Publish with GitHub Pages
1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Select branch **main** and folder **/(root)**, then Save.
4. Wait for GitHub Pages to publish. Expected URL:
   https://dhustlazops-cell.github.io/bacaan-yassin--tahlil/

## Content and accuracy notes
- Quranic Arabic, transliteration and Malay translation are requested from the AlQuran Cloud API at runtime. Internet access is required.
- Recitation audio uses AlQuran Cloud's documented audio CDN (Mishary Rashid Alafasy).
- Verify transliteration and translation against a trusted mushaf/teacher before leading a formal recitation.
- The Tahlil and doa section currently contains a short starter selection, not a complete locally approved Tahlil/Doa Arwah text. Have the imam/ustaz review and complete it according to the family's local practice.
- This site is a reading aid, not a replacement for a qualified imam or tajwid teacher.
